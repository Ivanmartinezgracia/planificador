## Inicializar el proyecto
````
npm init
````

## Descargar una dependencia (vite)
````
npm i -D vite
````
## Descargar una dependencia de produccion (dayjs)
````
npm i dayjs
````

## Probar la app en modo local (desarrollo)
````
npm run dev
````

## Construir la app
````
npm run build
````

## Arrancar la aplicación (modo producción)
````
npm run preview
````
